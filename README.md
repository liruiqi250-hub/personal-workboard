# 个人待办事项看板

**当前状态：开发预览，整体尚未通过最终验收。**

面向个人用户的中文工作待办看板。计划由每位使用者的 Codex 在各自 Windows 电脑部署本机网页服务，浏览器打开本机网址使用，个人数据库、账号设置和报告保存在各自电脑。

## 功能目标

- 从本人授权的微信、邮箱、钉钉工作来源整理待办，持续跟进原任务和完成依据。
- 提供分步中文设置向导、今日事项、逾期、等待回复和待确认任务。
- 生成日报、周报，支持保存位置设置和导出下载。
- 通过个人微信 Bot 接收日报，扫码连接，并在本人允许的项目范围内遥控本机 Codex。
- 通过 GitHub 分发版本，检测更新，保留上一版本和数据恢复路径。

## 安装发布状态

本仓库已作为后续公开分发入口建立，代码、给 Codex 的安装说明和经过验证的发行文件正在整理。**当前 README 不代表已经发布可供安装的正式版本。**

本机应用已有预览版本，任务操作、报告保存、重启持久化和本地升级回退已完成隔离验证；真实平台账号接入、实际网页交互、跨日微信推送及完整遥控仍需继续实现或验收。

待发行版本准备好后，本仓库会提供 README、AGENTS.md、docs/INSTALL_FOR_CODEX.md、维护脚本、版本记录和实际下载入口。请让 Codex 先读取这些文件，并按对应版本的实际检查结果部署；不要猜测下载链接或把未接入来源显示为已连接。

## 个人资料与授权

公开仓库用于分发程序和说明。每位使用者在自己的电脑配置本人的来源范围和账号，微信扫码、手机确认、邮箱及企业授权由本人完成。在线 AI 和微信发送的资料范围需分别按设置确认。

个人凭据、聊天记录、工作数据库和私人配置不属于本仓库的公开内容。
